# DepthForge-3D
Single-file Three.js and HTML5 Canvas studio that converts uploaded photos or procedural relief presets into depth-displaced 3D relief meshes with live side-by-side depth map previews and viewport shaders. Export watertight 3D models directly as Wavefront .OBJ (with companion .MTL and .PNG texture), binary .STL, and binary glTF 2.0 .GLB.
